01

Tokenization — Text to Numbers

Neural networks cannot process text directly. We convert every character to an integer. This is character-level tokenization — the simplest form.

Step-by-step Example

# Shakespeare text has 65 unique characters
chars = sorted(set(text))
# chars = ['\n', ' ', '!', '$', '&', "'", ..., 'z']

char_to_idx = {c: i for i, c in enumerate(chars)}

encode("Hello")   # [20, 43, 50, 50, 53]
decode([20, 43, 50, 50, 53])  # "Hello"

Why shift target by 1? — The training signal

Input  x:  [T, o, ' ', b,  e,  ' ', o,  r]
Target y:  [o, ' ', b, e,  ' ', o,  r,  ' ']

At pos 0: model sees "T"    -> must predict "o"
At pos 1: model sees "To"   -> must predict " "
At pos 2: model sees "To "  -> must predict "b"
...
One sequence gives context_length training examples!
⚡

Limitation: "cat" = 3 char tokens. With BPE, "cat" = 1 token. Shorter sequences = faster attention (O(n^2)) = more context per step. This is Assignment 3.

02

Token Embeddings — Numbers to Vectors

nn.Embedding(vocab_size, d_model) is a lookup table. Token ID 20 looks up row 20 of a 65x256 matrix. Each row is a 256-dimensional learned vector for that character.

# The embedding layer is a [65 x 256] learnable matrix
self.token_emb = nn.Embedding(65, 256)

idx   # shape: [batch=64, seq_len=256]  — integers 0..64
x = self.token_emb(idx)
# shape: [64, 256, 256] = [batch, seq_len, d_model]
# For each integer, it fetches the corresponding row from the weight matrix

What actually happens

token_emb.weight[20]  # 'H' -> vector of 256 learned floats
# e.g.: [0.012, -0.341, 0.872, 0.034, ..., -0.201]

token_emb.weight[43]  # 'e' -> different vector
# e.g.: [0.721,  0.023, -0.112, 0.456, ...,  0.334]

# After training: 'H' and 'h' cluster together,
# digits form one cluster, vowels another, etc.
💡

Weight Tying: self.lm_head.weight = self.token_emb.weight — The output projection reuses the embedding matrix. Saves 65x256 = 16,640 parameters and improves training stability.

03

RMSNorm — Stabilizing Activations

Without normalization, activations explode or vanish through deep layers. RMSNorm rescales each vector to have unit RMS, then applies a learned scale.

RMSNorm(x) = (x / RMS(x)) x weight where RMS(x) = sqrt( mean(x^2) + epsilon )

Numerical Example

# Input vector (d_model=8 for simplicity)
x = [3.0, -1.0, 2.0, 0.5, -2.0, 1.5, -0.5, 1.0]

# Step 1: Square each element
x_sq = [9.0, 1.0, 4.0, 0.25, 4.0, 2.25, 0.25, 1.0]

# Step 2: Mean of squares = 2.719
# Step 3: RMS = sqrt(2.719 + 1e-6) = 1.649

# Step 4: Normalize
x_norm = [1.82, -0.61, 1.21, 0.30, -1.21, 0.91, -0.30, 0.61]

# Step 5: Scale by learned weight (initialized to ones)
output = x_norm * weight   # element-wise multiply
class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))  # shape: [d_model]

    def forward(self, x):          # x: [B, S, d_model]
        rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)
        # rms: [B, S, 1]  — keepdim=True keeps the last dimension
        return (x / rms) * self.weight
        # [B,S,d] / [B,S,1] -> [B,S,d]  then * [d] -> [B,S,d]

RoPE — Rotary Position Embeddings

Transformers process all tokens in parallel with no built-in order. RoPE encodes position by rotating Q and K vectors by an angle proportional to their position. The rotation cancels in Q·K^T to give relative position.

The Rotation Formula

For pair (2i, 2i+1) at position pos: theta_i = 1 / (10000 ^ (2i / head_dim)) rotated[2i] = x[2i]*cos(theta*pos) - x[2i+1]*sin(theta*pos) rotated[2i+1] = x[2i]*sin(theta*pos) + x[2i+1]*cos(theta*pos)

Low frequency pairs (small theta) rotate slowly = capture global structure. High frequency pairs rotate fast = capture local/nearby patterns.

def precompute_rope_freqs(head_dim, max_seq_len, base=10000.0):
    freqs = 1.0 / (base ** (torch.arange(0, head_dim, 2).float() / head_dim))
    # freqs: [head_dim/2] = [16]  values from 1.0 down to ~0.0001

    positions = torch.arange(max_seq_len).float()  # [256]
    angles = torch.outer(positions, freqs)          # [256, 16]
    return torch.cos(angles), torch.sin(angles)     # both [256, 16]

def apply_rope(x, cos, sin):
    # x: [B, n_heads, S, head_dim]
    x1 = x[..., ::2]   # even dims: [B, H, S, 16]
    x2 = x[..., 1::2]  # odd  dims: [B, H, S, 16]

    cos = cos[:x.shape[2]].unsqueeze(0).unsqueeze(0)  # [1,1,S,16]
    out1 = x1*cos - x2*sin   # rotated even
    out2 = x1*sin + x2*cos   # rotated odd

    return torch.stack([out1, out2], dim=-1).flatten(-2)
    # interleave back: [B, H, S, head_dim]
✓

RoPE is applied to Q and K only — not V. Values carry information; only attention scores (Q.K) need position awareness.

05

Grouped Query Attention (GQA)

Standard attention: equal Q, K, V heads. GQA uses fewer K,V heads shared across groups of Q heads — 4x less KV memory. Used in LLaMA-2, Mistral, Gemma.

Our config: 8 Q heads, 2 KV heads (4:1 ratio)

Q heads:   Q0  Q1  Q2  Q3  Q4  Q5  Q6  Q7
                  |               |
KV heads:       KV0             KV1
           (serves Q0-Q3)  (serves Q4-Q7)

Full Annotated Forward Pass

def forward(self, x, rope_cos, rope_sin):
    b, seq, _ = x.shape         # x: [64, 256, 256]

    ## STEP 1 — Linear Projections
    q = self.q_proj(x)         # Linear(256->256): [64, 256, 256]
    k = self.k_proj(x)         # Linear(256->64):  [64, 256,  64]
    v = self.v_proj(x)         # Linear(256->64):  [64, 256,  64]

    ## STEP 2 — Reshape into heads
    q = q.view(b, seq, 8, 32).transpose(1,2)   # [64, 8, 256, 32]
    k = k.view(b, seq, 2, 32).transpose(1,2)   # [64, 2, 256, 32]
    v = v.view(b, seq, 2, 32).transpose(1,2)   # [64, 2, 256, 32]

    ## STEP 3 — Apply RoPE to Q and K
    q = apply_rope(q, rope_cos, rope_sin)       # [64, 8, 256, 32]
    k = apply_rope(k, rope_cos, rope_sin)       # [64, 2, 256, 32]

    ## STEP 4 — Expand KV to match Q (n_rep=4)
    k = repeat_kv(k, 4)   # [64, 8, 256, 32]
    v = repeat_kv(v, 4)   # [64, 8, 256, 32]

    ## STEP 5 — Scaled dot-product attention
    scale = 1.0 / math.sqrt(32)           # = 0.177
    scores = (q @ k.transpose(-2,-1)) * scale
    # [64,8,256,32] @ [64,8,32,256] = [64, 8, 256, 256]
    # scores[b,h,i,j] = "how relevant is token j to token i"

    ## STEP 6 — Causal mask (prevent attending to future)
    mask = torch.triu(torch.ones(seq, seq), diagonal=1).bool()
    # Example for seq=4:
    #  [[F,T,T,T],   T = masked (-inf) = future token
    #   [F,F,T,T],   F = visible (past + present)
    #   [F,F,F,T],
    #   [F,F,F,F]]
    scores = scores.masked_fill(mask, float("-inf"))

    ## STEP 7 — Softmax -> attention weights
    weights = F.softmax(scores, dim=-1)
    # [64, 8, 256, 256]  each row sums to 1.0
    # weights[b,h,i,j] = "fraction of attention from token i to token j"

    ## STEP 8 — Weighted sum of values
    out = weights @ v
    # [64,8,256,256] @ [64,8,256,32] = [64, 8, 256, 32]

    ## STEP 9 — Merge heads + output projection
    out = out.transpose(1,2).contiguous().view(b, seq, -1)
    # [64,8,256,32] -> [64,256,8,32] -> [64,256,256]
    return self.o_proj(out)   # Linear(256->256): [64, 256, 256]
🔢

Why scale by 1/sqrt(head_dim)? For head_dim=32, random Q,K dot products have variance ~32. Softmax of large values collapses to a one-hot (one token gets all attention). Scaling brings variance back to ~1, giving a spread-out attention distribution.

06

SwiGLU FFN — Knowledge Storage

If attention is "which tokens to look at", the FFN is "what to do with that information". It stores factual knowledge. The FFN holds about 2/3 of all model parameters.

Gate Mechanism — Step by Step

def forward(self, x):   # x: [64, 256, 256]

    gate = F.silu(self.w_gate(x))
    # w_gate: Linear(256 -> 680)
    # [64, 256, 680]
    # SiLU(z) = z * sigmoid(z)  — smooth, allows small negatives

    up = self.w_up(x)
    # [64, 256, 680]  — the "information" path

    hidden = gate * up
    # element-wise: [64, 256, 680]
    # The gate controls how much each dimension flows through

    return self.w_down(hidden)
    # Linear(680 -> 256): [64, 256, 256]

SiLU vs ReLU

x:      [-2.0,  -1.0,  0.0,  1.0,  2.0]
ReLU:   [ 0.0,   0.0,  0.0,  1.0,  2.0]  <- kills all negatives (dead neurons)
SiLU:   [-0.24, -0.27, 0.0, 0.73, 1.76]  <- small negatives pass through
                                              -> smoother gradients -> better training
07

TransformerBlock — Stacking it all

One TransformerBlock = GQA + SwiGLU with residual connections and pre-norm. This block is repeated 4 times.

x input
→
RMSNorm(x)
→
GQA
→
x = x + attn_out
→
RMSNorm(x)
→
SwiGLU
→
x = x + ffn_out
def forward(self, x, rope_cos, rope_sin):  # x: [B, S, 256]

    # Sub-layer 1: Attention (pre-norm + residual)
    x = x + self.attention(self.attn_norm(x), rope_cos, rope_sin)
    # The +x is the residual connection — preserves original information

    # Sub-layer 2: FFN (pre-norm + residual)
    x = x + self.ffn(self.ffn_norm(x))

    return x   # same shape [B, S, 256]
💡

Why residual connections? x = x + f(x) means gradients flow directly backwards through + without passing through any transformation. This prevents vanishing gradients and lets us stack 4, 8, 32+ layers.

08

MiniLLM — Full Forward Pass

def forward(self, idx, targets=None):
    b, seq_len = idx.shape
    # idx: [64, 256]  — token IDs (integers)

    x = self.token_emb(idx)        # [64, 256, 256]

    for layer in self.layers:
        x = layer(x, self.rope_cos, self.rope_sin)
    # x stays [64, 256, 256] through all 4 blocks

    x = self.final_norm(x)         # [64, 256, 256]
    logits = self.lm_head(x)       # [64, 256,  65]
    # logits[b, t, v] = score for char v at position t in batch b

    loss = None
    if targets is not None:
        loss = F.cross_entropy(
            logits.view(-1, logits.size(-1)),   # [16384, 65]
            targets.view(-1)                     # [16384]
        )
    return logits, loss

Training Loop — Loss, Backprop, Optimizer

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)

for step in range(MAX_STEPS):

    xb, yb = get_batch("train", BATCH_SIZE, CONTEXT_LEN)
    # xb: [64, 256]   yb: [64, 256]

    logits, loss = model(xb, yb)
    # loss: scalar cross-entropy between predictions and targets

    optimizer.zero_grad()
    # ALWAYS zero gradients first — they accumulate by default

    loss.backward()
    # PyTorch walks computation graph backwards
    # Computes d(loss)/d(param) for every parameter — chain rule

    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    # If total gradient norm > 1.0, scale all gradients down
    # Prevents exploding gradients

    optimizer.step()
    # AdamW: param = param - lr * (momentum / sqrt(variance) + wd * param)
    # Adaptive per-parameter learning rate — much better than plain SGD

Understanding Cross-Entropy Loss

# logits for one position: [-1.2, 3.4, 0.1, ..., -0.5]  (65 values)
# target = 43  (character 'e')

# Softmax gives probabilities. Say prob[43] = 0.7
# Cross-entropy = -log(0.7) = 0.36  (good!)

# If prob[43] = 0.01:
# Cross-entropy = -log(0.01) = 4.6  (bad!)

# Random baseline (65 chars equally likely):
# loss = -log(1/65) = 4.17

# After 3000 steps training: loss ~ 1.5-2.0
# Loss of 0.0 would mean perfect prediction (impossible on real text)

Assignment 3 — Implement BPE Tokenization

Byte Pair Encoding starts with characters and repeatedly merges the most frequent adjacent pair into one token. After training, common words/subwords become single tokens.

The Algorithm

  • 1
    Start with all unique characters as vocabulary
  • 2
    Count frequency of every adjacent pair in corpus
  • 3
    Merge the most frequent pair into a new single token
  • 4
    Repeat steps 2-3 for N iterations (num_merges)
  • 5
    Apply learned merges greedily to encode new text

Complete Implementation

from collections import Counter

class BPETokenizer:
    def __init__(self, num_merges=500):
        self.num_merges = num_merges
        self.merges  = {}   # (pair_tuple) -> merged_string
        self.vocab   = {}   # token_string -> token_id
        self.inv_vocab = {} # token_id -> token_string

    def _get_stats(self, word_freqs):
        """Count all adjacent pairs in corpus."""
        pairs = Counter()
        for word, freq in word_freqs.items():
            symbols = word.split()
            for i in range(len(symbols) - 1):
                pairs[(symbols[i], symbols[i+1])] += freq
        return pairs

    def _merge_vocab(self, best_pair, word_freqs):
        """Merge the best pair in all words."""
        bigram = " ".join(best_pair)
        merged = "".join(best_pair)
        return {w.replace(bigram, merged): f for w, f in word_freqs.items()}

    def train(self, text):
        """Learn BPE merges from text corpus."""
        # Split text into words, convert each to space-separated chars
        # The </w> marker indicates end-of-word: "cat" -> "c a t </w>"
        word_freqs = Counter()
        for word in text.split():
            word_freqs[" ".join(list(word)) + " </w>"] += 1

        # Initial vocabulary = all unique characters + </w>
        all_chars = set()
        for word in word_freqs:
            all_chars.update(word.split())
        self.vocab = {c: i for i, c in enumerate(sorted(all_chars))}

        # Iteratively merge the most frequent pair
        for merge_idx in range(self.num_merges):
            stats = self._get_stats(word_freqs)
            if not stats: break

            best = max(stats, key=stats.get)
            word_freqs = self._merge_vocab(best, word_freqs)

            merged_token = "".join(best)
            self.merges[best] = merged_token
            self.vocab[merged_token] = len(self.vocab)

            if (merge_idx + 1) % 100 == 0:
                print(ff"Merge {merge_idx+1}: '{best[0]}' + '{best[1]}' -> '{merged_token}'")

        self.inv_vocab = {v: k for k, v in self.vocab.items()}
        print(ff"Final vocab size: {len(self.vocab)}")

    def encode(self, text):
        """Text -> list of token IDs."""
        ids = []
        for word in text.split():
            # Apply merges greedily in order they were learned
            symbols = list(word) + ["</w>"]
            while True:
                pairs = [
                    (symbols[i], symbols[i+1])
                    for i in range(len(symbols) - 1)
                    if (symbols[i], symbols[i+1]) in self.merges
                ]
                if not pairs: break
                # Apply merge with highest priority (earliest learned)
                merge_order = list(self.merges.keys())
                best = min(pairs, key=lambda p: merge_order.index(p))
                merged = self.merges[best]
                for j in range(len(symbols) - 1):
                    if symbols[j] == best[0] and symbols[j+1] == best[1]:
                        symbols = symbols[:j] + [merged] + symbols[j+2:]
                        break
            ids.extend([self.vocab.get(s, 0) for s in symbols])
        return ids

    def decode(self, ids):
        """Token IDs -> text string."""
        return "".join([self.inv_vocab.get(i, "?") for i in ids]).replace("</w>", " ")
